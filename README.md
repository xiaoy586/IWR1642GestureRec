# IWR1642GestureRec
This repository contains the official PyTorch implementation and dataset scripts for the paper:

 Wang, X.; Wu, H.; Zheng, J.; Zhang, Y. Embedded mmWave Radar-Based Hand Gesture Recognition Using a Dual-Stream LSTM and Attention-BiGRU Network. *Electronics* 2026, 15, 3973. https://doi.org/10.3390/electronics15173973.

## Abstract

We propose a lightweight dual-stream recurrent network for hand gesture recognition based on TI IWR1642 FMCW millimeter-wave radar. The framework separately encodes range-Doppler kinematic features and temporal sequential features via LSTM branches, followed by an Attention-BiGRU module to capture long-range temporal dependencies of gesture motion. The model is optimized for low-latency inference and deployment on embedded edge devices, targeting real-time on-chip gesture sensing.
